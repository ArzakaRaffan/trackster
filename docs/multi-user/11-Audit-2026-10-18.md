## 3. Cara deploy perubahan infrastruktur

- `docker-compose.prod.yml` berubah untuk backend/frontend/nginx (logging, `NODE_OPTIONS`) → ketiganya dibuat ulang saat deploy.
  Postgres & certbot **tidak** diubah (tidak di-restart).
- Config Nginx baru diuji di kontainer sekali-pakai **sebelum** apa pun di-restart (`deploy.yml`); gagal → folder `nginx/`
  dikembalikan ke versi sebelumnya dan deploy berhenti. Setelah `up -d`, `nginx -s reload` dijalankan eksplisit.
- Tidak ada migrasi DB, tidak ada env baru wajib.
